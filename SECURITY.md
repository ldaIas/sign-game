# Security policy

Zodle is a static site with no accounts, no server-side code and no personal data. If you find a security problem anyway (for example a way to run script on the page or a weakness in the headers or service worker), please report it privately.

## How to report

Use GitHub's private vulnerability reporting: go to the repository's **Security** tab and choose **Report a vulnerability**, or open <https://github.com/ldaIas/sign-game/security/advisories/new>.

Please don't open a public issue for security problems. This is a hobby project, so replies are best-effort, but reports are welcome and appreciated.

## Supported versions

Only the live site at <https://signs.idalas.com/> (the `main` branch) is supported.
