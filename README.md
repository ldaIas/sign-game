# Zodle

A small browser quiz: you're shown a birthday and have to name its sun sign. Play it at <https://signs.idalas.com/>.

## Modes

- **Daily** — one birthday a day, the same for everyone (picked from the player's local date). Answer five questions in order: sign, symbol, gender, element, opposite sign. Each question appears only once the previous one is answered. You get 5 misses across the whole puzzle; run out and every answer is revealed. Wrong sign guesses get an "N signs ahead/behind" hint. Progress and the day streak (consecutive days solved) are kept in your browser. This is the mode the page opens in.
- **Classic** — 3 guesses per birthday. Get it right and you earn a bonus question: name the sign's element (1 guess).
- **Timed** — 60 seconds, 1 point per correct sign, one guess per birthday.
- **More** — practice games: draw lines matching each sign name to its symbol, or sort all twelve signs by gender, modality or element in one try.

Signs follow the Western (tropical) zodiac, using its common fixed dates; birthdays that fall on a cusp follow those dates.

Behind the game is a twinkling starfield. A correct sign in any mode briefly pulls nearby stars into that sign's constellation.

## Install it

Zodle works as an app (PWA) and still opens offline after the first visit. Chrome and Edge show an **Install** button; on iPhone and iPad, use **Share → Add to Home Screen**.

## Privacy and accessibility

No cookies, analytics or accounts; scores and streaks stay in your own browser's local storage. The game is playable by keyboard and screen reader and respects reduced-motion settings. The full notices are in the page footer.
